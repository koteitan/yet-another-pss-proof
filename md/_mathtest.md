# math delivery test

## A: math fence, double backslash
```math
\begin{aligned}
A &= 1,\\
B &= 2.
\end{aligned}
```

## B: math fence, \cr
```math
\begin{aligned}
A &= 1,\cr
B &= 2.
\end{aligned}
```

## C: math fence, array with newline command
```math
\begin{aligned}
A &= 1, \newline
B &= 2.
\end{aligned}
```

## D: dollar-dollar, quadruple backslash
$$
\begin{aligned}
A &= 1,\\\\
B &= 2.
\end{aligned}
$$

## E: math fence, no aligned (single line)
```math
A = 1, \quad B = 2.
```
