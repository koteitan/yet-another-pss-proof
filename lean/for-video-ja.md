## 0. 用語の対応

既存シリーズと証明本文は、同じものを違う名前で呼んでいる。突き合わせに必要な分だけ並べる。

### 0.1 2 つの親子関係

```
P0(x) = 自分より左で、1 行目の値が自分より小さい、いちばん右の列
P1(x) = P0 の木で x の先祖である列のうち、2 行目の値が自分より小さい、いちばん右の列
```

$`P_1`$ が**先祖しか見ない**のがこの体系の要で、先祖でない列は 2 行目が小さくても飛ばされる。
証明本文での名前は $`P_0`$ = [D.nextrel0](Pss-ja.md#d-nextrel0)、
$`P_1`$ = [D.nextrel1](Pss-ja.md#d-nextrel1)。同じものである。

例：$`(0,0)(1,1)(2,0)(1,1)`$ では、列 3 の $`P_1`$ は列 2 ではなく列 0 になる。
列 2 は 2 行目が $`0`$ で $`1`$ より小さいが、列 3 の先祖をたどると列 0 へ飛ぶので、
列 2 は別の枝にいて候補に入らない。

### 0.2 翻訳 tr が読むもの

1 行目の値は、左から読むと 1 ずつしか増えない
（[D.steps1](Seqlex-ja.md#d-steps1)、[T.blockok_ST_PS](Seqlex-2-ja.md#t-blockok_ST_PS)）。
つまり 1 行目は**森の行きがけ順の表記**になっている。ある列の**部分木**とは、
その列より右で、1 行目の値がその列より大きい列が続く限りの範囲である。

```
tr(())        = Z
tr(p :: 残り)  = P( p の 2 行目の値,
                    tr(p の部分木),
                    tr(残り) )
```

$`p_a(b) + c`$ の

- $`a`$ = **その列の 2 行目の値**
- $`b`$ = **その列の部分木**（1 行目で見た部分木）
- $`c`$ = 右に残る森

### 0.3 展開の言葉

| 既存シリーズ | 本文 |
|---|---|
| 刈る列 | 末尾の列 $`j_1 = \lvert M\rvert - 1`$ |
| バッドルート | 親 $`j_0`$（[D.parent](Pss-ja.md#d-parent)） |
| 良い部分 | $`M`$ の先頭 $`j_0`$ 列（`take`） |
| 悪い部分 | ブロック |
| 上昇量 | $`d_0`$ |
| 階段 | 上昇コピー（$`i_1 = 1`$ の分岐） |
| ただ消える | $`\mathrm{Pred}`$（末尾を落とす） |

**コピーの個数の数え方だけ違う。** 既存シリーズは活性化関数 $`f(n) = n^2`$ を使って
$`f(n)+1`$ 個並べる。本文の $`M[n]`$ は $`n`$ 個（$`n \ge 1`$）で、$`f`$ を固定せず
$`n \ge 1`$ 全部について同時に扱う。数を突き合わせるときはここに注意する。

## 全体の設計図

最終目標は

```
展開関係 step は整礎である（無限に展開し続けることはできない）
```

第 3 章で「展開の 1 歩は測度 $`\mathrm{tr}(M)`$ を真に減らす」が済んでいる。
残るのは**測度の順序 $`\prec`$ が標準形の像の上で整礎**であること。これが第 4 章と第 5 章の全部である。

整礎性は次の 2 本の柱で示す（Buchholz 1987 §2 の方法）。

```
柱 1  Bachmann 共終性  : N ≺ M なる標準形 N は、ある n で N ⪯ M[n]
柱 2  反復帰納的集合 W_u : どの標準形もある u で W_u に属する
柱 1 + 柱 2 ⟹ 整礎性
```

第 4 章はこの 2 本を建てるための**足場**、第 5 章が**柱そのもの**である。

## 第 I 部 舞台を項から列へ移す

### 主命題

> **標準形の上で、項の順序と列辞書式順序は一致する。**
> $`M \ne N`$ なる標準形について
> $`\mathrm{tr}\,M \prec \mathrm{tr}\,N \iff M \prec_{\mathrm{lex}} N`$
> （[T.olt_ST_iff_seqlex](Seqlex-2-ja.md#t-olt_ST_iff_seqlex)）

列辞書式順序は素朴な定義である。

```
seqlex(M, N)  :≡  M が空で N が空でない、または
                  先頭が異なるなら先頭の対の辞書式比較、
                  先頭が等しいなら尾部どうしの再帰
```

### なぜこれが第 4 章で一番効くのか

これ以降、**項 $`p_a(b)+c`$ は登場しない**。木を見なくても、数列を左から見て
最初に違う列の対を比べるだけで大小が決まる。第 5 章の議論はすべて列の上で行われるので、
この同型が舞台を作っている。

### 証明の筋

1. 標準形はブロックである（[T.blockok_ST_PS](Seqlex-2-ja.md#t-blockok_ST_PS)）。
   ブロックとは「先頭の 1 行目が $`d`$、全列の 1 行目が $`d`$ 以上、隣接段差 1 以下」
2. ブロック $`B`$ の先頭列の部分木と残りは、$`\mathrm{tr}`$ の再帰の 2 つの引数にちょうど対応する
   （[T.blockok_arg](Seqlex-ja.md#t-blockok_arg)、[T.blockok_tail](Seqlex-ja.md#t-blockok_tail)）
3. 2 つの列の**最初の差は、部分木の側か残りの側のどちらかに現れる**
   （[T.seqlex_arg_or_tail](Seqlex-ja.md#t-seqlex_arg_or_tail)）。これが再帰を回す鍵
4. 長さの和に関する帰納法で同型が出る

### 難所

- **[T.blockok_oper](Seqlex-2-ja.md#t-blockok_oper)（展開はブロックを保つ）** — Lean 179 行、
  Isabelle 365 行で、この部で最大。難しさは、悪い部分が $`n`$ 個並ぶとき、
  **繋ぎ目で隣接段差 1 以下が壊れないこと**を言う点にある。コピーとコピーの境目では
  1 行目の値が「悪い部分の末尾」から「次のコピーの先頭」へ飛ぶので、そこが 1 以下であることを、
  上昇量 $`d_0`$ と絡めて評価する必要がある

## 第 II 部 標準形の形

第 I 部で舞台は列になった。第 III 部の議論は「標準形はこういう形をしている」という
性質を大量に使う。それを用意するのがこの部で、**主命題が 3 つある**。

### II-1 Cantor 標準形条件

> **標準形の翻訳は cnf をみたす**（[T.cnf_ST_PS](Cnf-3-ja.md#t-cnf_ST_PS)）

```
cnf(Z)                 :⟺ 真
cnf(P(a,b,Z))          :⟺ cnf(b)
cnf(P(a,b,P(e,f,g)))   :⟺ cnf(b) かつ P(a,b,Z) ⊀ P(e,f,Z) かつ cnf(P(e,f,g))
```

主要項の和が広義単調減少している、という条件で、順序数の Cantor 標準形
$`\omega^{a_1} + \dots + \omega^{a_k}`$（$`a_1 \ge \dots \ge a_k`$）の指数の減少条件にあたる。
森で言えば、左から並ぶ木の根が「同じか小さくなる」ということである。

証明は $`\mathrm{ST\_PS}`$ の帰納法で、対角列（基底段）と展開（帰納段）の 2 つ。
帰納段が本体で、完全コピー分岐と上昇コピー分岐に分かれる。

### II-2 接頭辞不変性

> **列の前に何を足しても、後半の中の構造は変わらない**
> （[T.entry_append_right](Column-ja.md#t-entry_append_right) から
> [T.parent_append_right](Column-ja.md#t-parent_append_right) までの一群）

親子関係、祖先関係、親の存在、探索行、展開のすべてが前置に不変で、
さらに**1 行目の親子は前置と後半の境界を越えない**
（[T.nextrel0_no_cross](Column-ja.md#t-nextrel0_no_cross)）。

これがあるので、第 III 部では「注目している悪い部分だけ見ればよい」と言い切れる。
共終性の証明が局所的な議論で済むのは、ひとえにこの部のおかげである。

### II-3 位置的不変量 r1ok と z0ok

> **標準形は次の 2 つをみたす**
> （[T.r1ok_ST_PS](Column-3-ja.md#t-r1ok_ST_PS)、[T.z0ok_ST_PS](Column-4-ja.md#t-z0ok_ST_PS)）

```
r1ok(M) :≡ 1 行目が正の列には必ず親（1 行目がちょうど 1 小さい直近の列）があり、
           その列の 2 行目は、親の 2 行目より高々 1 しか大きくない
z0ok(M) :≡ 1 行目が 0 の列は、2 行目も 0
```

この 2 つから**親の存在と一意性**（[T.parent0_exists](Column-4-ja.md#t-parent0_exists)、
[T.parent1_exists](Column-4-ja.md#t-parent1_exists)、[T.hp_last](Column-4-ja.md#t-hp_last)）が出る。
展開の定義には「親がなければ末尾を落とす」という分岐があるので、
**標準形では刈る列に必ずバッドルートがある**と言えて初めて、その分岐を潰して
第 4 分岐だけを相手にできる。

### 難所

- **[T.cnf_ctx_cong](Cnf-2-ja.md#t-cnf_ctx_cong)（条件の文脈による合同）** — Lean 160 行。
  難しさの正体は、**翻訳 $`\mathrm{tr}`$ が連結について合成的でない**ことである。
  先頭の列の部分木の中身は「後ろに何が来るか」で決まるので

  ```
  cnf(tr(G ++ X))  と  cnf(tr G) かつ cnf(tr X)
  ```

  は同値にならない。同じ $`G`$ でも、後ろに 1 行目の小さい列が来れば木はそこで切れ、
  大きい列が来れば同じ木に取り込まれる。したがって
  「後半を差し替えても条件が残る」を言うには、差し替えの前後で何が不変かを条件として
  すべて書き下すしかなく、実際 6 つの仮定が要る
- **[T.r1ok_copyExp](Column-2-ja.md#t-r1ok_copyExp)（複製展開における 2 行目の規律）** — Lean 118 行、
  Isabelle 452 行。コピーが $`n`$ 個並んだとき、$`k`$ 番目のコピーの中の列の親が
  「同じコピーの中」なのか「前のコピー」なのかで場合が分かれ、後者では上昇量
  $`d_0`$ の分だけ添字の計算がずれる。添字の商と剰余の分解
  （[T.index_decomp](Column-2-ja.md#t-index_decomp)）を軸に、位置の計算を全部書き下すことになる
- **上昇コピー分岐の CNF 保存**（[T.cnf_oper_i1eq1](Cnf-3-ja.md#t-cnf_oper_i1eq1)、
  [T.cnf_copies](Cnf-3-ja.md#t-cnf_copies)）— 概念は難しくないが手数が多い。
  入れ子の持ち上げの塔 $`\mathrm{cp}_d(B, n+1) = B \mathbin{+\!\!+} \mathrm{sh}_d(\mathrm{cp}_d(B,n))`$
  を段ごとに崩し、そのたびに「この列全体が 1 本の木になる形」と「尾部の 1 行目の下界」を作り直す

## 第 III 部 Bachmann 共終性（柱 1）

### 主命題

> **$`M`$ より真に小さい標準形は、$`M`$ の基本列のどれかで上から抑えられる。**
> 標準形 $`M, N`$ が $`\mathrm{tr}\,N \prec \mathrm{tr}\,M`$ をみたすなら、
> ある $`n \ge 1`$ があって $`\mathrm{tr}\,N \preceq \mathrm{tr}(M[n])`$
> （[T.pss_cofinality_holds](Final-ja.md)、核は
> [T.pss_cofinality_of_argdom](Cofinality-3-ja.md#t-pss_cofinality_of_argdom)）

$`M`$ の下にぶら下がる標準形は無数にあるが、どれを取っても
$`M[1], M[2], M[3], \dots`$ のどれかが上から覆う、という主張である。

### 還元の階段

証明は 5 段の還元でできている。

```
(1) 項の順序での共終性
      ↓ 第 I 部の順序同型
(2) 列辞書式順序での共終性         D.SeqlexCofinality
      ↓ 展開の 4 分岐で場合分け
(3) 第 4 分岐だけが残る            他の 3 分岐は末尾を落とすだけで易しい
      ↓ 完全コピーと上昇コピーに分ける
(4) 2 つの「核心」                 T.crux_zero と D.AscCrux
      ↓ 宿主（周りの列）を消す
(5) 宿主に依らない核               D.ArgDomCore
```

### 第 4 分岐の核心が言っていること

$`N \prec_{\mathrm{lex}} M`$ とする。$`M[n]`$ は悪い部分を $`n`$ 個並べたものだから、
$`N`$ を覆うには「$`n`$ を大きくすればコピーの列がいくらでも右に伸びる」ことを使う。
問題は、$`N`$ が $`M`$ とどこまで一致していて、どこで下回るかが分からないことである。

- **完全コピー**（[T.crux_zero](Cofinality-2-ja.md#t-crux_zero)）：
  コピーは全部同じ形なので、$`N`$ の分岐点を含むだけコピーを取れば覆える
  （[T.copy_dom_zero](Cofinality-2-ja.md#t-copy_dom_zero)）
- **上昇コピー**（[D.AscCrux](Cofinality-2-ja.md#d-AscCrux)）：
  コピーが 1 個ごとに階段状に上がるので、同じ形の繰り返しにならない。
  ここが本当の難所で、次の ArgDomCore に還元される

### 宿主に依らない核 ArgDomCore

> **1 つの標準形の中で、2 行目の値が同じ $`w`$ である 2 つの列が、1 行目で祖先・子孫として
> 並んでいるとする。その 1 行目の値を $`u`$ と $`u+e`$ とすると、子孫の側の部分木 $`B`$ は、
> 祖先の側の部分木 $`A`$ を $`e`$ だけ持ち上げたものに、列辞書式順序で覆われる。**
> （[D.ArgDomCore](ArgDom-ja.md#d-ArgDomCore)、成立は
> [T.argDomCore_holds](ArgDom-5-ja.md#t-argDomCore_holds)）

```
1 行目 u+e   (u+e, w) ← 子孫の側。部分木 B
                |        （1 行目で祖先・子孫、2 行目はどちらも w）
1 行目 u     (u, w)   ← 祖先の側。部分木 A = A1 ++ (u+e,w) :: (B ++ A2)
```

条件 SpineOK は「2 つの列の間にある、右から見える列の 2 行目はすべて $`w`$ 以上」、
すなわち**この 2 つが 2 行目について兄弟である**ことを言っている。

なぜ「宿主に依らない」のが大事かというと、この形にすると**周りの列 $`X`$ と $`Z`$ が消える**
からである。第 II 部の接頭辞不変性が、この消去を可能にしている。

### ArgDomCore の証明

$`\mathrm{ST\_PS}`$ の帰納法（[T.argDomCoreOn_ST_PS](ArgDom-5-ja.md#t-argDomCoreOn_ST_PS)）。
基底段は対角列で自明に近く、帰納段が展開の第 4 分岐で、そこがさらに 3 つの場合に割れる。

| 場合 | 状況 | 規模 |
|---|---|---|
| A1 | 印を付けた 2 列が同じコピーの中に収まる | Lean 44 行 |
| B | 2 列が悪い部分の外にある | Lean 185 行 |
| **A2** | **2 列がコピーの境界をまたぐ** | **Lean 461 行 / Isabelle 1519 行** |

### 難所

- **[T.argDomCoreOn_bad_A2](ArgDom-4-ja.md#t-argDomCoreOn_bad_A2)** —
  **この証明全体で最大の補題**で、Lean で 461 行、Isabelle で 1519 行ある。
  本文でも 1 つの補題だけで 1 ページを占めている。
  難しさは、印を付けた 2 つの列がコピーの境界をまたぐとき、
  一方は $`k`$ 番目のコピー、他方は $`k'`$ 番目のコピーに属し、
  **階段の持ち上げ量が両者で違う**ことにある。
  ArgDomCore の結論は「$`e`$ だけ持ち上げる」という一様な平行移動なので、
  ひとつの $`e`$ で両方を揃えることができない。
  そこで列を水準で分割し（[T.arg_split](ArgDom-2-ja.md#t-arg_split)）、
  持ち上げの合成と逆（[T.shiftl0_shiftr0](ArgDom-2-ja.md#t-shiftl0_shiftr0)、
  [T.shiftr0_comm](ArgDom-2-ja.md#t-shiftr0_comm)）を使って、
  異なる持ち上げ量を持つ 2 つの断片を共通の宿主の上に載せ直して比較する
- **[T.copy_dom_zero](Cofinality-2-ja.md#t-copy_dom_zero)** — Lean 124 行。
  完全コピーの側の核心。$`n`$ を十分大きく取れば覆えることを、$`n`$ に一様なブロック分解
  （[T.oper_bad_blocks_all](Cofinality-ja.md#t-oper_bad_blocks_all)）の上で示す

## 第 IV 部 反復帰納的集合 $`W_u`$（柱 2）

### 主命題

> **どの標準形も、ある $`u`$ で $`W_u`$ に属する**（[T.W_membership](Wset-4-ja.md#t-W_membership)）

しかも $`u`$ は具体的に取れて、**2 行目の値の最大値**でよい
（[T.mem_W_maxr1](Wset-4-ja.md#t-mem_W_maxr1)）。

### $`W_u`$ とは何か

作用素 $`A_u`$ の最小不動点である（[D.Aop](Wset-ja.md#d-Aop)、[D.W](Wset-ja.md#d-W)）。
$`A_u(X)`$ に入る列は次の 3 種類。

```
(1) 長さ 1 以下で、2 行目が 0                    —— 底
(2) 孤児でない列で、全ての n について M[n] ∈ X   —— 刈れば必ず既知の形になる
(3) ある m < u について M が「2 行目の孤児」で、
    W_m の任意の（1 行目が 0 から始まる）z に対し graft(M, z) ∈ X
                                                 —— 下のレベルから接ぎ木できる
```

「2 行目の孤児」とは、末尾の列の 2 行目が $`m+1`$ で、しかも 2 行目に親がない、という意味である
（[D.domT](Wset-ja.md#d-domT)）。接ぎ木 graft は、その末尾の列を取り除いて、
そこにあった 1 行目の値から $`z`$ を積み直す操作である（[D.graft](Wset-ja.md#d-graft)）。

最小不動点なので、2 つの原理が使える。

```
(A1) A_u(W_u) = W_u        不動点方程式        T.A1
(A2) A_u(Y) ⊆ Y ⟹ W_u ⊆ Y  帰納法の原理       T.A2
```

$`W_u`$ の定義は $`u`$ より小さいレベルの $`W_m`$ を参照するので、$`u`$ についての再帰と
各レベルでの最小不動点が二重になっている。これが「反復帰納的」の意味である。

### 主命題の証明の筋

1. すべての列が $`W^{*}`$ に属する（[T.mem_Wstar](Wset-4-ja.md#t-mem_Wstar)）。ここで
   $`W^{*} = \{R \mid R \text{ の全列の 1 行目が正ならば、任意の } v \text{ で } (0,v) :: R \in W_v\}`$
2. そのために $`A_u(W^{*}) \subseteq W^{*}`$（[T.Wstar_closed](Wset-4-ja.md#t-Wstar_closed)）を示し、
   (A2) を使う
3. 2 行目の値の上界からレベルを取れば所属が出る（[T.mem_W_of_bound](Wset-4-ja.md#t-mem_W_of_bound)）

### 難所

- **[T.Wstar_closed](Wset-4-ja.md#t-Wstar_closed)** — Lean 104 行、Isabelle 489 行。
  $`A_u`$ の 3 分岐それぞれについて、左端に根 $`(0,v)`$ を足した列が $`W_v`$ に入ることを示す。
  分岐 (2) では、根を足した列を刈った結果が「元の列を刈った結果に根を足したもの」に
  なることが要る
- **[T.oper_cons_nat](Wset-3-ja.md#t-oper_cons_nat)** — Lean 94 行、Isabelle 497 行。
  上の「根を足しても展開が可換」を言う補題。根を 1 つ足すと全列の添字が 1 ずれるので、
  1 行目の親子・祖先、2 行目の親、探索行のすべてについてずれを追う必要がある
  （[T.entry_cons](Wset-3-ja.md#t-entry_cons) から
  [T.nextR_cons_last](Wset-3-ja.md#t-nextR_cons_last) までの一群がそのための道具）
- **塔 $`\mathrm{tow}`$**（[D.tow](Wset-3-ja.md#d-tow)）— 接ぎ木を $`k`$ 回繰り返した列。
  $`t_0 = ()`$、$`t_{k+1} = (0,v) :: \mathrm{graft}(R, t_k)`$。
  2 行目の孤児の位置に、下のレベルの列が次々と入っていく操作である

## 第 V 部 合流

2 本の柱が揃うと結論が出る（[T.wf_of_cofinality_and_membership](Wset-4-ja.md#t-wf_of_cofinality_and_membership)）。

```
柱 2 で M ∈ W_u を取る
  ↓ W_u の帰納法（A2）
M は到達可能（Acc）である            T.acc_of_W
  ↓ 柱 1（共終性）を使って、M より小さい標準形を M[n] で覆う
標準形上の順序は整礎
  ↓ 第 3 章の測度の減少
展開関係 step は整礎、無限展開列は存在しない
```

$`W_u`$ の帰納法の分岐 (2) が「刈れば既知の形になる」であることと、共終性が
「小さいものは刈った先で覆える」であることが、ちょうど噛み合う。
**ここが証明全体の要である。**

## 説明の重みづけ

内容としてどこに時間をかける価値があるか、という目安だけ書く。

1. **全体の設計図** — ゴールと 2 本の柱
2. **第 I 部** — 順序同型。舞台が列に移る、という転換点なので厚く
3. **第 II 部** — 主命題 3 つ（cnf、接頭辞不変性、r1ok と z0ok）だけでよい。**証明はスキップ可**。
   補題の数は多いが、個々は道具である
4. **第 III 部** — 還元の階段を通しで見せてから、ArgDomCore に時間をかける。ここが山
5. **第 IV 部** — $`W_u`$ の 3 分岐と塔
6. **第 V 部** — 2 本の柱が噛み合って整礎性が出る。締め

時間をかけるべきは第 I 部の順序同型、第 III 部の ArgDomCore、第 IV 部の塔の 3 つである。
